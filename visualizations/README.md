# Tableau Dashboards

This directory contains two Tableau dashboard exports created for the Rogers Wireless Revenue Analytics case study.

## Dashboard 1 — Industry Benchmark

Compares Rogers and CRTC industry trends in wireless service revenue growth, subscriber growth, and ARPU growth.

## Dashboard 2 — Revenue Driver Analysis

Shows the modeled subscriber and ARPU effects on Rogers' 2025 wireless service revenue, alongside actual year-over-year changes.

The revenue bridge includes a reconciliation residual, which is not an independently verified operational driver.

Data sources: Rogers Communications financial reports and CRTC communications market data.
